# 카카오맵 연동 (내 맛집 지도) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로그인한 손님이 지금까지 방문/주문한 매장을 `react-kakao-maps-sdk`로 그린 지도 위 핀으로 볼 수 있는 `/stores/map` 페이지를 만든다.

**Architecture:** `view_logs`를 `stores`에 조인해 로그인 유저가 실제로 조회/주문한 매장만 골라내는 DB 함수 하나, 좌표 평균을 계산하는 순수 함수 하나, 그리고 그 둘을 조합해 로그인 게이트 + 빈 상태 + 지도 렌더링을 하는 페이지 하나로 구성한다. 새 테이블/스키마 변경 없음 — 기존 `stores.latitude/longitude`, `view_logs`만 읽는다.

**스펙 대비 구현 결정 1건:** 스펙은 `app/api/stores/visited/route.ts` GET API를 거치는 걸 전제했지만, 실제로는 `app/dashboard/page.tsx`(점주 진입 라우터)가 이미 쓰고 있는 패턴 그대로 — Server Component인 `/stores/map` 페이지가 `auth()` + `getVisitedStoresByUser()`를 직접 호출한다. 지도는 클라이언트 컴포넌트가 필요하지만 "데이터 조회"까지 클라이언트로 갈 필요는 없어서, 별도 API 라우트 없이 서버 컴포넌트가 데이터를 가져와 클라이언트 컴포넌트에 props로 내려준다. 동작은 스펙과 동일(로그인 필요, 방문 매장만, 없으면 빈 상태) — fetch 왕복 하나와 중복 인증 체크를 줄이는 구현상의 단순화다.

**Tech Stack:** `react-kakao-maps-sdk` (+ 타입용 `kakao.maps.d.ts`), Next.js 15 App Router (Server Component가 DB 조회, Client Component가 지도 렌더)

**Spec:** [docs/superpowers/specs/2026-09-03-kakao-map-design.md](../specs/2026-09-03-kakao-map-design.md)

## Global Constraints

- 지도에는 로그인 유저의 `view_logs`에 기록이 있는 매장만 표시한다 — 등록된 전체 매장을 보여주는 탐색형 기능이 아니다 (스펙: 범위 밖).
- `/stores/map`은 로그인 필수다. 비로그인 접근 시 로그인 유도 화면을 보여주고 지도는 렌더링하지 않는다 (스펙: 페이지 설계).
- 지도 핀 클릭 → 이동하는 메뉴판 링크는 테이블 번호 없이 여는 열람 전용이라는 걸 화면 문구로 안내한다 (스펙: 페이지 설계 — QR 스캔이 아니므로 주문 흐름과 구분).
- `NEXT_PUBLIC_KAKAO_MAP_KEY`는 카카오 "지도" 앱의 **JavaScript 키**를 쓴다 (Local API에 쓰는 `KAKAO_REST_API_KEY`와는 다른 키, 이미 `.env.local`에 설정됨) — 헷갈리지 말 것 (스펙: 기술 선택).
- 실제 카카오 계정 로그인이 필요한 검증 단계는 어떤 자동화 주체(에이전트/서브에이전트)도 대신 수행하지 않는다 (안전 정책 — 다만 이번 플랜은 세션이 이미 로그인된 상태라면 새 로그인 자체는 필요 없을 수 있다, Task 5 참고).

```ts
/** 지도 초기 중심 계산에 필요한 최소 좌표 형태 (Store와 호환) */
export interface GeoPoint {
  latitude: number | null;
  longitude: number | null;
}

/**
 * 매장 좌표들의 평균 중심을 계산한다.
 * 좌표가 없는(null) 매장은 제외하고, 남는 매장이 하나도 없으면 null을 반환한다.
 */
export function averageCenter(
  points: GeoPoint[],
): { lat: number; lng: number } | null {
  const valid = points.filter(
    (p): p is { latitude: number; longitude: number } =>
      p.latitude != null && p.longitude != null,
  );
  if (valid.length === 0) return null;

  const sum = valid.reduce(
    (acc, p) => ({ lat: acc.lat + p.latitude, lng: acc.lng + p.longitude }),
    { lat: 0, lng: 0 },
  );
  return { lat: sum.lat / valid.length, lng: sum.lng / valid.length };
}
```

```tsx
"use client";

/// <reference types="kakao.maps.d.ts" />

import { useEffect, useState } from "react";
import Link from "next/link";
import { CustomOverlayMap, Map, MapMarker, useKakaoLoader } from "react-kakao-maps-sdk";
import type { Store } from "@/lib/types";
import { averageCenter } from "@/lib/mapView";

const FALLBACK_CENTER = { lat: 37.5665, lng: 126.978 }; // 서울시청 (매장 전부 좌표 없을 때만)

export default function MapCanvas({ stores }: { stores: Store[] }) {
  const appkey = process.env.NEXT_PUBLIC_KAKAO_MAP_KEY ?? "";
  const [loading, error] = useKakaoLoader({ appkey });
  const [map, setMap] = useState<kakao.maps.Map | null>(null);
  const [selectedId, setSelectedId] = useState<number | null>(null);

  const points = stores.filter(
    (s): s is Store & { latitude: number; longitude: number } =>
      s.latitude != null && s.longitude != null,
  );
  const center = averageCenter(points) ?? FALLBACK_CENTER;
  const selected = points.find((s) => s.id === selectedId) ?? null;

  useEffect(() => {
    if (!map || points.length < 2) return;
    const bounds = new kakao.maps.LatLngBounds();
    points.forEach((p) =>
      bounds.extend(new kakao.maps.LatLng(p.latitude, p.longitude)),
    );
    map.setBounds(bounds);
  }, [map, points]);

  if (!appkey) {
    return (
      <p className="blurb">
        NEXT_PUBLIC_KAKAO_MAP_KEY가 설정되지 않았어요 (.env.local 확인)
      </p>
    );
  }
  if (error) {
    return <p className="blurb">지도를 불러오지 못했어요.</p>;
  }
  if (loading) {
    return <p className="empty">지도를 불러오는 중…</p>;
  }

  return (
    <Map
      center={center}
      style={{ width: "100%", height: "60vh" }}
      onCreate={setMap}
    >
      {points.map((s) => (
        <MapMarker
          key={s.id}
          position={{ lat: s.latitude, lng: s.longitude }}
          onClick={() => setSelectedId(s.id)}
        />
      ))}
      {selected && (
        <CustomOverlayMap
          position={{ lat: selected.latitude, lng: selected.longitude }}
          yAnchor={1.4}
        >
          <div className="map-overlay">
            <strong>{selected.name}</strong>
            <Link href={`/stores/${selected.id}`}>메뉴 보기 (열람 전용)</Link>
          </div>
        </CustomOverlayMap>
      )}
    </Map>
  );
}
```

```tsx
import { auth, signIn } from "@/auth";
import AppHeader from "@/app/ui/AppHeader";
import { getVisitedStoresByUser } from "@/lib/db";
import MapCanvas from "./MapCanvas";

export default async function MyMapPage() {

    return (
      <>
        <AppHeader title="내 맛집 지도" />
        <div className="section">
          <p className="muted" style={{ marginTop: 0 }}>

            action={async () => {

              await signIn("kakao", { redirectTo: "/stores/map" });
            }}
          >
            <button className="btn" type="submit">
              카카오로 로그인
            </button>
          </form>
        </div>
      </>
    );
  }

  const stores = await getVisitedStoresByUser(session.user.id);

  if (stores.length === 0) {
    return (
      <>

      </>

  return (
    <>
      <AppHeader title="내 맛집 지도" sub={`${stores.length}곳`} />

  );
```
